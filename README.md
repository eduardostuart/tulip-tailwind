# tulip-tailwind

Tailwind CSS plugin for tulip — injects the [Tailwind Play CDN](https://tailwindcss.com/docs/installation/play-cdn) script into every page.

> **Note:** This uses the CDN version which includes all Tailwind classes. For production, consider using the Tailwind CLI for tree-shaken output.

## Install

```bash
tulip plugin add https://github.com/eduardostuart/tulip-tailwind
```
